## Overworld

{{< figure src="/images/overworld-1.png" title=地图最初的样子 >}}
{{< figure src="/images/overworld-2.png" title=完成overworld的样子 >}}

这部分是整个游戏中最开始的地方。在这裡，你将学习基本规则以及规则创建的过程。我建议你解决所有七个关卡，这些关卡都不应该对你造成太大的困扰，而且每个关卡中的知识都是后面游戏所必须的。

## Level 00

{{< figure src="/images/overworld-lv00.png" >}}

**难易度**: 无

**新物件**：名词 **Baba**、**Flag**、**Wall** 和 **Rock**。如果你的眼睛还没认出来，那麽你应该能从其名词意义及颜色中分辨出来。此外，还有新的属性 **You**、**Win**、**Stop** 和 **Push**，以及操作符 **Is**。

每当你看到新物件时，探索这些新物件的含义是很重要的。每个规则都是以「名词 Is 属性」的形式拼写，这意味着什麽？尝试移动看看。哪个物件会移动？这可能是 **You** 吗？将 **Baba** 移动到任何 **Wall**，这透露出 **Stop** 的含义是什麽？现在移动到任何 **Rock**，这告诉你 **Push** 的含义是什麽？你能将 **Rock** 推向另一个 **Rock** 吗？那麽推向 **Wall** 呢？那麽推到 **Flag** 上呢？如果 **Baba** 站在 **Flag** 上会怎样？这表示 **Win** 代表什麽？

{{< admonition type=tip title="提示 💡" open=false >}}
无

我并不是故意不给提示，但如果在这裡你已经需要提示，那麽你可能一点都不会喜欢这款游戏
{{< /admonition >}}

## Level 03: Out of Reach

{{< figure src="/images/overworld-lv03.png" >}}

**难易度**: ☆☆

**新物件**：名词 **Water**，应该很明显。属性 **Sink**。

尝试让 **Baba** 穿过水面。发生了什麽？他们踩到的那块水又发生了什麽变化？这告诉你关于 **Sink** 规则代表什麽？

此外，你可能有注意到，有些规则似乎无法更改，这是正常的。事实上，大多数的关卡只允许你编辑一部分规则。面对每一个关卡时，建议先弄清哪些规则是固定的，哪些是可以更改的。

{{< admonition type=tip title="提示 💡" open=false >}}
你是否对如何完成这一关做出了某种假设，比如与 **Flag** 有关的假设？也许这个假设是错的。
{{< /admonition >}}

{{< admonition type=tip title="提示 💡💡" open=false >}}
要让 **Baba** 碰到 **Flag** 也许是个错误的假设。
{{< /admonition >}}

## Level 04: Still Out of Reach

{{< figure src="/images/overworld-lv04.png" >}}

**难易度**: ☆

**新物件**：名词 **Skull**，那个红色的东西。属性 **Defeat**。

把 **Baba** 放到任何一个 **Skull** 上。**Baba** 会发生什麽？**Skull** 会发生什麽？其他物件能与 **Skull** 重叠吗？重叠后那个物件会发生什麽变化？经过这些测试，**Defeat** 代表什麽意思呢？

{{< admonition type=tip title="提示 💡" open=false >}}
有一条规则使得这关不可能过关。也许你可以打破这条规则？
{{< /admonition >}}

___

## Level 05: Volcano

{{< figure src="/images/overworld-lv05.png" >}}

**难易度**: ☆☆☆

**新物件**：名词 **Lava**，像是 **Water** 但是是橘红色的。属性 **Hot** 与 **Melt**。

让 **Baba** 走到一块 **Lava** 上。发生了什麽？现在把 **Rock** 推到任何一块 **Lava** 上。这次会发生什麽？对于 **Hot** 和 **Melt** 的作用可以得到什麽结论？**Hot** 和 **Melt** 之间有什麽关联？此外，**Hot** 和 **Melt** 与 **Defeat** 在操作上有什麽相似之处？它们有什麽不同？

这款游戏中的许多关卡有多种解法，比如这关。大部分情况下我不会列出所有解法，我只会列出我认为最接近开发者预设的解法。如果你找到了一个不一样的解法，那非常好！

{{< admonition type=tip title="提示 💡" open=false >}}
你需要在不破坏「Baba is You」的情况下通过这一关。该如何做到这一点？为什麽破坏规则时游戏会结束？
{{< /admonition >}}

{{< admonition type=tip title="提示 💡💡" open=false >}}
看起来有三个文字可以自由移动。这些文字能组成一条规则吗？
{{< /admonition >}}

## World Complete!

完成外部世界其实没获得什麽宝物，只是能解锁另外两条路。其中一条通往一扇上锁的门，需要花朵才能打开。在通过几个世界之前，你无法前往那裡。所以，你得走上方的路，前往湖泊区（The Lake）。
